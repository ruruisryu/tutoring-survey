# 운영 설정 예시

관리자 화면에 입력할 내용의 형식 예시입니다. 실제 선생님 소개·수업료·환불 규정은 저장소에 넣지 않고 관리자 화면에서 직접 입력합니다.
(실제 문구 원문은 저장소에서 제외된 로컬 파일 `private/운영-문구-원문.md`에 있습니다.)

결과를 약속하는 표현(“성적을 올려드립니다” 등), 확인할 수 없는 경력·후기, 이모지는 쓰지 않습니다.

## 운영 설정 → 선생님 소개

```
○○·○○ 과목을 1:1 화상 수업으로 지도합니다.

(선생님이 직접 겪은 공부 경험이나 이력 — 사실만)

수업에서는 개념 이해 → 문제 적용 → 오답 분석 → 복습의 과정을 학생이 스스로 해낼 수 있도록 지도합니다. 학생이 문제를 푸는 모습을 보면서 어떻게 접근하는지, 어느 개념에서 막히는지, 어떤 실수를 반복하는지 확인합니다.

수업은 (화상 도구)로 진행합니다.
```

## 운영 설정 → 수업료·환불·취소 안내

```
환불은 (적용하는 환불 규정)을 따릅니다.
(당일 취소·불참 시 처리 규칙)
```

## 수업 관리 → 새 수업 만들기

| 수업 이름 | 과목 | 대상 | 수업 방식 | 회당 시간 | 주당 횟수 | 확정 조건 |
| --- | --- | --- | --- | --- | --- | --- |
| 중등수학 정규 클래스 | 수학 | 중학교 1·2·3학년 | 화상 | 120분 | 비워두고 ‘학부모가 고를 수 있는 주당 횟수’에서 주 1회·주 2회 체크 | 회당 시간 |
| 중등과학 정규 클래스 | 과학 | 중학교 1·2·3학년 | 화상 | 120분 | 위와 같음 | 회당 시간 |
| 통합과학 정규 클래스 | 통합과학 | 고등학교 (필요한 학년 체크) | 화상 | 120분 | 위와 같음 | 회당 시간 |
| 내신 집중 대비 클래스 (과목별) | 해당 과목 | 해당 학교급 | 협의 (학부모가 화상·대면 중 선택) | 120분 | 비워둠 | 회당 시간, 수업 기간 |

- 수업 안내 칸에는 수업 방식, 수업료(회차·기간 기준), 대면 수업 장소·추가 비용처럼 그 수업에만 해당하는 내용을 적습니다.
- 요일·시간대를 고르지 않으면 학부모가 가능한 요일과 시작 시각을 자유롭게 고릅니다. 특정 시간대 반(예: 토요일 오전)만 운영하려면 그 수업에 요일·시간대를 넣고 ‘요일 확정’을 체크하세요.

## 초대 링크

- 과목이 정해진 상담이면 수업 1개 고정 링크
- 아직 과목을 정하지 않은 상담이면 ‘여러 수업 중에서 학부모가 고르게 하기’를 켜고 여러 수업을 연결
